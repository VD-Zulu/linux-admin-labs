# Linux Administration Labs
Hands-on exercises covering essential Linux system administration tasks — process inspection, package management, service control, log analysis, environment variables, web server testing, troubleshooting workflows, and professional evidence documentation.
## 🧠 Labs Overview
This repository contains a series of practical Linux labs designed to build real‑world administration proficiency.

| Lab | Focus Area | Description |
|-----|-------------|-------------|
| Lab 03 | System Identification | Explore hostname, user, and kernel information. |
| Lab 05 | Package Management | Install, update, and verify software packages. |
| Lab 06 | Service Control | Manage systemd services and verify statuses. |
| Lab 08 | Log Investigation | Inspect and interpret system logs. |
| Lab 10 | Web Server Testing | Validate Nginx configuration and uptime. |
| Lab 15 | Professional Evidence | Document operational outputs and troubleshooting notes. |
## 🧩 Skills Demonstrated
- Linux command‑line proficiency  
- System and service management using systemd  
- Package installation and updates with apt  
- Log analysis and troubleshooting  
- Environment variable configuration  
- Evidence‑based documentation practices  
- Git version control and repository management
